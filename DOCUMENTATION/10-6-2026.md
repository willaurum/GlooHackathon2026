# AI Church Website Templatizer

The templatizer is **an application that asks a church about ten questions, learns from its existing website or uploaded files, and uses AI to build a website tailored to that church.**

## 1. Gather what the church already has

The church can enter its existing website URL, upload documents and photos, or start by answering questions.

If it provides a URL, the application scrapes the website to find information such as service times, location, ministries, beliefs, and branding. Uploaded files can provide the same information.

The application uses what it finds to prefill answers so the church can confirm or correct them.

## 2. Ask about ten questions

The agent asks question catered to discovering more about the church. It should check to see if the church has a pre-existing site and if it does it should scrape the site or get the files before asking additional questions. Any info that the agent cannot find is left out, not created.

## 3. Ask clarifying questions

AI compares the answers with the scraped website and uploaded materials. It asks focused follow-up questions when something is missing, unclear, or contradictory.

For example:

> Your website lists a 9:00 AM service, but your bulletin lists 10:00 AM. Which time should the new site show?

> You mentioned a children's ministry. What ages does it serve, and when does it meet?

> You want visitors to plan a visit. Should they fill out a form or simply see directions and service times?

Unknown facts are left out rather than invented. The church confirms the information used to build its site.

## 4. AI builds the website

AI uses the church's answers, preferences, and materials to choose layouts, organize pages and navigation, write suggested copy, apply branding, and place relevant photos.

For example, a church that prioritizes new visitors could receive a homepage with:

- A welcoming introduction and church photo
- A prominent **Plan your visit** button
- Service times and directions
- Information about children's programs
- An explanation of what to expect
- Upcoming events and ways to connect

Behind the scenes, the framework gives AI reusable website components and rules for combining them. These provide the layouts and working features AI uses to build each church's site.

The agent will check and fix its own work, **where judges can see it.** After it builds the site, the agent should check church.json/site.json against your schema, render the preview, and confirm every fact on the page traces back to a source. If something doesn't, it fixes it or asks the church. Show this in the UI as a visible step list ("Checking facts… 2 unsupported claims removed").

## 5. Preview, request changes, and publish

The church sees its generated website and can edit it directly or ask AI for changes:

> Make the homepage feel more traditional.

> Put our service times above the ministries section.

> Use the photos we uploaded and shorten the welcome message.

When the church is happy with the preview, it publishes the site. Future changes can be reviewed in a draft before going live.

## JSON Customization

Each church’s website is defined by JSON files. The templatizer uses questionnaire answers, scraped website information, and clarifying questions to generate these files.

- church.json stores church information, such as service times, ministries, and contact details.
- site.json defines the website’s colors, fonts, pages, layouts, and section order.

The proposed templatizer adds the guided application that gathers information, asks follow-up questions, and uses AI to build a personalized church website using those capabilities.
