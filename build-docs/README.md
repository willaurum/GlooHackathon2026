# Build documentation

The Tekton build documentation for the 2026 Gloo AI Hackathon (Agents of Flourishing track):
the Agent Build Document and anything that supports it, such as prompts, evaluation cases and
session logs.

Everything in this folder is licensed under **CC BY 4.0** (see [LICENSE](LICENSE)), so other builders
can reuse it with credit. The Tekton software itself is not: all rights in it are reserved (see the
[LICENSE](../LICENSE) at the repository root).

- [references.md](references.md): the published guidance on agent design, tool use, evaluation,
  human-in-the-loop and agent security that Tekton follows, mapped to the code.

Put build documents here. The draft outline currently lives at `docs/Agent-Build-Doc.md`; move it
here when it is ready to publish, and keep anything that should not be shared openly (keys, private
notes, real people's information) out of this folder.
